# IGN-Metadata-Injector
Adds game data from IGN and HowLongToBeat on a Steam or Epic game page

<img width="1368" height="891" alt="image" src="https://github.com/user-attachments/assets/05f19331-8cdb-4586-bbd4-89862f208961" />


## Features
 - IGN Rating and User Score
 - Developer name
 - HowLongToBeat data
 - HowLongToBeat Leisure time 
 - Steam Reviews (extracted from the page)
 - ESRB Rating
 - IGN award/leaderboard
 - Select which parameters you want to be shown
 - Allow rearranging of parameters
 - Selecting positioning of the overlay
 - HowLongToBeat data can be separated
 - Per-title overrides (in case of mismatched title names)
 - Works on all browsers
 - Userscript available for easy install and updates
 - can be integrated on Steam app for desktop
  
# Installation

*Planned release as a Firefox Add-on*

# Userscript: 

  *Requires Tampermonkey extension or any Userscript Manager* :  **[Install](https://raw.githubusercontent.com/alphaxleonidas/IGN-Metadata-Injector/main/ign-metadata-injector.user.js)**

# Chrome/Steam

-  Download the `Chrome` version from the [Releases](https://github.com/alphaxleonidas/IGN-Metadata-Injector/releases)

-  Extract the file.

-  Go to `chrome://extensions`

-  Enable `Developer Mode` on the top right.

-  Select `Load Unpacked`

-  Select the extracted folder.

-  The extension should work

# Firefox

-  Download the `Firefox` version from the [Releases](https://github.com/alphaxleonidas/IGN-Metadata-Injector/releases)

-  Go to `about:config`

-  Change `xpinstall.signatures.required` to `false`

-  Go to `about:addons`

-  Click the settings icon above the add-ons. Choose `install add-on from file`

-  Select the firefox zip

-  The extension should work.
